Sobre mí

Mi nombre es Christopher Fabrizio Cárdenas Angulo, soy desarrollador Frontend Junior. Hago páginas web interactivas y funcionales, utilizando HTML, CSS, JavaScript, PHP y SQL. Trabajo con frameworks y librerías como React, Laravel, Bootstrap, Tailwind CSS y Sass. También uso Git, GitHub, Bitbucket, PhpMyAdmin, Vite y Laragon . Manejo metodologías de gestión de proyectos como Scrum y Jira, y en diseño web con Figma y WordPress.
